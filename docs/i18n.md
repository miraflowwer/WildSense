# Interface Languages (i18n)

**Audience:** developers. **Last updated:** 2026-08-13 (v1.1.0).

GAHM ships an English / ಕನ್ನಡ (Kannada) / தமிழ் (Tamil) interface for the
operational dashboard, with a zero-dependency custom i18n layer.

## Scope

| Translated | Intentionally English |
| --- | --- |
| Auth screens, header, filters, KPI bar, alert list & detail, detection form, outcome form, SMS simulator chrome, risk-engine explainer, map caption & tooltips | Guided tour, ethics modal, landing page, SMS community warning templates (4-language by design) |

## How it works

- `src/i18n/catalog-en.ts` is the source of truth: `enRaw` (`as const`), the
  derived `Catalog` shape, and the `TKey` leaf-path union (typed `t()` keys).
  `catalog-kn.ts` / `catalog-ta.ts` are plain `Catalog` objects.
- `I18nProvider` (`src/i18n/I18nContext.tsx`) exposes `t(key, params)`, `lang`,
  `setLang`, and the raw `catalog` (for the engine helpers). It syncs
  `document.documentElement.lang` and `localStorage['gahm.lang']`.
- **Per-account preference:** with a signed-in Supabase user, the pick writes
  through to `public.user_settings.preferred_language`; a local pick made
  before sign-in wins on sign-in, otherwise the account value loads.
  Requires the `user_settings` table — see `docs/supabase-schema-and-fixes.sql`
  §4 (run in the Supabase SQL Editor once).
- `src/i18n/helpers.ts` maps **stored data values** to display strings:
  `speciesName`/`speciesDesc`, `weatherName`/`weatherDesc`, `statusLabel`,
  `riskLevelLabel`, `reasonLabel`/`reasonDescription`, `uncertaintyWarning`.
- The risk engine emits stable `ContributionReason.key` values
  (`src/engine/riskEngine.ts`) that the alert panel maps to translated labels;
  number-bearing descriptions (proximity/history/group) intentionally stay in
  English. Stored status/outcome values are never translated in storage — only
  at display time.
- Dates/times use `en-IN`/`kn-IN`/`ta-IN` locales via `LOCALE_IDS`.

## Adding a string

1. Add the key to `enRaw` in `catalog-en.ts` (any nesting; `t('a.b')`).
2. Add the same key to `catalog-kn.ts` and `catalog-ta.ts` — the `Catalog`
   type fails the build if a key is missing.
3. Use `const { t } = useI18n()` in the component.

## Translation quality

Kannada and Tamil strings were machine-drafted. The ~50 demo-critical strings
(auth, filters, ops bar, alerts, forms, SMS chrome, risk explainer) must be
reviewed by a native speaker before Demo Day (2 Sep 2026) — see the review
note in `docs/implementations/improved-auth-security.md` era docs / AGENTS.md.
